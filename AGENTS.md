# Project Guidelines & User Preferences

## Language & Technology Constraints

- **STRICT PROHIBITION: NEVER USE TYPESCRIPT.**
  - The user does NOT use TypeScript under any circumstances.
  - Never generate `.ts` or `.tsx` files.
  - Never generate `tsconfig.json`.
  - Never install or configure `typescript`, `ts-node`, `tsc`, `@types/*`, or any TypeScript-specific tooling.
  - Always write pure modern JavaScript (`.js`, ES modules) for all frontend applications, consoles, Node.js utilities, tools, and scripts.
